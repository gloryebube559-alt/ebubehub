# @Ebubehub — Dark Futuristic Gaming Hub

A responsive static multi-page starter site. No build step or paid framework is required.

## Sitemap
- `index.html` — homepage and featured sections
- `games.html` — searchable/filterable starter game directory
- `news.html` — editorial topic cards (replace with verified articles)
- `guides.html` — practical gaming tips
- `community.html` — community plans and contribution links
- `about.html` — mission and editorial promise
- `contact.html` — contact form demo
- `privacy.html` — starter privacy note to customise

## Test locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Test the mobile menu, game search, genre filter, and contact form on your phone.
4. In `script.js`, replace `YOUR_EMAIL@example.com` with the email address you want visitors to contact.
5. Replace starter news topics with original, fact-checked articles and add licensed artwork if desired.

## Publish free
- Create a GitHub account if you do not already have one.
- Create a new public repository named `ebubehub` and upload all files in this folder.
- In repository Settings → Pages, choose deploy from the `main` branch and the root folder, then save.
- GitHub Pages will provide a public URL after deployment. You can later connect a domain you own.
- Alternative: deploy the folder using Netlify Drop or Cloudflare Pages' direct upload flow; check current provider requirements.

## Important before launch
- The contact form is a mailto demo, not a hosted form backend. Replace the placeholder email.
- The sample games are examples for discovery; check platform availability and links before publishing.
- News cards are topic placeholders, not current news.
- The privacy note is a template, not legal advice. Update it to match actual analytics, hosting, forms, cookies, and services.
- No account system, comments, live chat, tournaments, or game file hosting is included.
- Only use artwork and logos you own, have permission to use, or are licensed to use.
